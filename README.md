# 🚀 Viajando - Plataforma Web de Reservas Turísticas

Aplicación web desarrollada como trabajo práctico de Desarrollo Web, enfocada en la simulación de una plataforma de reservas de alojamientos turísticos. El proyecto implementa una interfaz moderna, responsive y funcional utilizando HTML5, CSS3 y Bootstrap 5.

---

# 📌 Descripción del Proyecto

**Viajando** es una plataforma web orientada al sector turístico que permite a los usuarios:

- Iniciar sesión en la plataforma.
- Visualizar alojamientos disponibles mediante tarjetas interactivas.
- Realizar reservas completando formularios validados.
- Consultar un resumen de reservas realizadas.

El objetivo principal del proyecto fue desarrollar una experiencia visual moderna, intuitiva y adaptable a distintos dispositivos.

---

# 🖥️ Tecnologías Utilizadas

- HTML5
- CSS3
- Bootstrap 5
- Responsive Design
- Formularios HTML con validaciones
- Componentes Cards y Tables
